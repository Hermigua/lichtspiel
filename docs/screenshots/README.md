# Screenshots / Bildschirmfotos

Place screenshots of Lichtspiel here (PNG or JPG, ideally 1920×1080 or smaller).
Hier Bildschirmfotos von Lichtspiel ablegen (PNG oder JPG, am besten 1920×1080 oder kleiner).

Suggested file names / Vorgeschlagene Dateinamen:

| Datei | Inhalt |
|---|---|
| `home.png` | Startseite (Weiterschauen, Nächste Folge, Neu in …) |
| `library.png` | Bibliothek mit Postern, Filter und Sortierung |
| `detail.png` | Detailseite eines Films oder einer Serie |
| `player.png` | Web-Player mit Kapiteln, Tempo, Schlaf-Timer |
| `live-overview.png` | Senderübersicht Live-TV (Bühne, Standbilder, Gruppen) |
| `epg.png` | Programmführer |
| `channels.png` | Eigene Sender |
| `radio.png` | Radio mit „Läuft gerade“ |
| `stats.png` | Statistik |
| `tv-app.png` | Android-TV-App |

Do not include personal data in screenshots (real user names, private server addresses, your own stream URLs).
Keine persönlichen Daten auf den Bildern (echte Benutzernamen, private Serveradressen, eigene Stream-Adressen).
